Both columns approach the same number from opposite sides. That shared number is the limit. If the two sides disagree, the limit does not exist and there is no derivative there (try |x| at a = 0).

Where the formula comes from

Start with something you already trust: the slope of a straight line through two points, slope = rise / run. For a line, any two points give the same answer, so “the slope” is well defined.

A curve breaks this. Different pairs of points give different slopes. The secant through A and B only tells you the average steepness between them. Physically: if f(t) is position, the secant slope is average velocity over the interval [a, a+h].

What we want is the steepness at A alone, like the number on a speedometer. Taking B = A directly gives rise 0 and run 0, so 0/0, which is meaningless. That is the whole problem. The limit is the way around it: we never set h = 0, we ask which value the quotient approaches as h gets arbitrarily close to 0.

How to read each symbol

  1. a is the fixed point where you want the slope. h is how far to the right (or left, if negative) the second point is.
  2. f(a+h) − f(a) is the rise: the change in height between the two points.
  3. h in the denominator is the run: (a + h) − a.
  4. The fraction is the secant slope. lim h→0 means: the number the fraction gets as close to as you like, provided h is close enough to 0 (but not equal to it).

Read aloud: “f prime of a is the limit, as h goes to zero, of f of a plus h minus f of a, all over h.”

Why the two forms in your notes are the same

In the first form the second point is called x; in the second it is called a + h. Substitute x = a + h. Then x − a = h, and x → a is the same statement as h → 0. Nothing changes but the label for the second point.

Why it is called the derivative

For each a you get one number f′(a). Now let the point vary: replace a by x and you get a new function f′(x), which outputs the slope of f at every x. It is derived from f, hence the name. Example: for f(x) = x², f′(x) = 2x.

Worked by hand: f(x) = x²

f(a+h) − f(a) = (a² + 2ah + h²) − a² = 2ah + h². Divide by h (allowed, since h ≠ 0): 2a + h. Now let h → 0: the result is 2a. Notice that we cancelled h before taking the limit. That cancellation is exactly what turns the meaningless 0/0 into something finite.
